是一个不断加速的环。

不追求“看完了”，只追求“真的跑起来了”。每次折腾都必须留下一个脚本、一条判断标准，或者一次以后不会再踩的坑。

02 / FIELD WORK

不是“会用工具”，
是拿工具解决真问题。

下面这些不是课程作业，都是从“我现在就想把它弄明白”开始。

CASE_001 / INFRASTRUCTURE

把旧设备、云服务器和手机，串成一套自己的执行网络。

不是为了堆配置。把远程连接、中转和命令行执行理顺之后，机器在哪里不重要，任务在哪里跑才重要。

Debian · Tailscale · SSH · Linux · 网络排障
CASE_002 / AUTOMATION

重复任务，从“提醒我”进化到“机器直接做”。

定时执行、状态检查、异常才通知。把注意力留给真正需要判断的地方。

Python · Playwright · cron · 日志
CASE_003 / DECISION SYSTEM

让多个 AI 分工，而不是开一堆对话框。

一个负责总控，一个负责重执行；事实源只留一个，避免重复、冲突和空转。

Muse · Codex · CLI · 单一事实源

三条硬规矩。

先纠错，再回答

方向错了，速度越快离目标越远。先把理解偏差拆出来，再谈方案。
